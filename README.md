# XSMN iPhone App V4
- Cào kết quả công khai và lưu kỳ quay.
- Đối chiếu bộ số với kết quả thực tế.
- Lưu lịch sử trên server.
- Thống kê khớp đúng, 2 số cuối, 3 số cuối theo từng số.
- Xuất cơ sở dữ liệu JSON.
Chạy: npm install && node server.js
Lưu ý: bộ cào phụ thuộc cấu trúc HTML của nguồn; dữ liệu chỉ là tham chiếu thống kê.
